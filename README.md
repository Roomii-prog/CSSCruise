# CSS Cruise Website

A simple Next.js + Tailwind CSS business website for CSS Cruise.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Run locally:

```bash
npm run dev
```

3. Open `http://localhost:3000` in your browser.

## Notes

- The site uses a placeholder `public/logo.svg` logo. Replace it with the final logo image when available.
- Instagram link is set to `https://instagram.com/css.cruise`.
- Course details are based on the provided CSS Précis 2026 information.
